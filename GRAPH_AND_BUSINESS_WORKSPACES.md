# DAKSH graph, gestures and business workflows

Open `/Applications/DAKSH.app`. Brain Graph is the default workspace. Search, zoom, drag nodes, select a record and open it in the corresponding workspace. Scope changes rebuild the graph from that scope only. Type hubs show membership; dashed links represent explicit, unambiguous `[[title]]` references, not inferred knowledge.

Gesture Deck: select Camera-free demo to explore the interface. Start camera gestures requests webcam permission. Frames are processed locally with bundled MediaPipe assets. Stop deck, switch views, or change scope to stop processing. This is note-deck control, not desktop or screen-recording automation; bundled upstream 3D props are omitted.

Business Skills: choose a finance or agency template, supply relevant facts, and run with an installed Ollama model. Download the resulting text as Markdown or PDF. These are model-written drafts: validate calculations, evidence, jurisdiction and accounting treatment. Use the existing deterministic Finance workspace for checked calculations. No paid model, upstream installer, delegated agent or external account action is invoked by these workflows.

Upstream source and license records are under `third_party/`. The public brain-map is a 2D graph; the paid/members-only Brain Studio interface was not copied. The public repository inventory covers all 80 repositories returned on 15 September 2026, reviewing README and license availability, not every source file or runtime.

Known old builds are preserved in a private archive before removal, as recorded in RETIRED_DAKSH_COPIES.md. Current dist output, installed application and current Xcode build are intentional copies of the same updated application. GitHub source updates are followed by the existing main-branch watcher; native Swift changes require rebuilding the app.

Remaining acceptance: one live spoken instruction and reply in the packaged app, live webcam gesture operation, native report-save dialog, and optional production WhatsApp activation. Gmail drafts stay unsent for review.
