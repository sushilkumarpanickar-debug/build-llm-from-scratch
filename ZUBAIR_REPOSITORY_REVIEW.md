# Zubair Trabzada repository review

Reviewed 15 September 2026 from GitHub's public repository API and selected source README/LICENSE files. 80 public repositories returned. This is a suitability review, not an installation or runtime verification.

## DAKSH priorities

1. **brain-map**: first UI reference. Public MIT code offers a local interactive graph, growth animation, pan/zoom, node dragging, highlighting and search. Markdown links define relationships; it is not a semantic RAG engine. The public README places 3D galaxy mode and advanced Brain Studio features in a members-only product. No public repository named JARVIS Odyssey was identified in the returned inventory.
2. **holo-gestures**: optional local gesture deck. Original code is MIT; bundled MediaPipe is Apache-2.0 and Three.js MIT. Requires webcam permission. Camera gestures manipulate its note UI; they are not general macOS computer control. Review native WebKit camera compatibility before integration.
3. **ai-finance-claude**: useful finance planning workflows and report templates. Raw LICENSE verified as MIT despite GitHub metadata showing NOASSERTION. Adapt workflow concepts to local Ollama and deterministic calculations; Claude Code compatibility does not make inference free.
4. **ai-agency-claude** and **ai-ads-claude**: MIT workflow/orchestration references. Adapt selectively for SNNS marketing and agency work, without executing their global installers.
5. **ai-legal-claude**: do not vendor yet. LICENSE was not found at the root raw URL, and its README requires Claude Code with an active Anthropic API key. Indian statutory work needs separate official-source verification.
6. Other sales, proposal, recruiting, reputation, marketing and SEO suites are candidate task modules. Their individual code, licenses and dependencies have not yet been audited.
7. **scroll-cinematic-claude** advertises Higgsfield-generated assets; paid service dependencies and licensing remain unverified. It is not a priority for the private local assistant.

## Implementation direction

Keep DAKSH's local Ollama, SQLite, RAG, voice and communication services. Replace its presentation with a graph workspace that uses actual scoped documents, explicit memories, tasks and approvals. Preserve upstream notices for any MIT code adapted. Build original 3D behavior where the public upstream does not supply it. Add screen capture and computer actions through a separate Mac permission and approval layer; neither graph repo provides those capabilities by itself.
